allowed-tools: Read, Glob, Grep, Agent
argument-hint: <調べたいことを複数、カンマまたは改行で区切って>
description: 独立した調査を orchestra:explorer に並列で投げて統合する
---

## 調べること

$ARGUMENTS

## 進め方

1. 依頼を、互いに依存しない調査単位に分割する。分割できない（前の結果が次の入力になる）ものは並列にせず、その旨を明示して順に実行する。
2. 各単位を orchestra:explorer に並列で委譲する。1 回のファンアウトは 4 件までにする。それ以上は文脈が膨らむだけで精度が落ちる。
3. 各エージェントには「結論と、根拠になったファイルパスと行番号だけを返す」ことを明示して渡す。
4. 返ってきた結果を統合する。統合時に以下を必ず確認する。
   - 複数のエージェントの結論が矛盾していないか。矛盾していればそのまま両論を提示する。片方を勝手に採用しない。
   - 「見つからなかった」という報告を「存在しない」に格上げしていないか。
5. 以下の形式で報告する。

```
## 調査結果
### <調査単位1>
- 結論
- 根拠: path:line

## 矛盾・未解決
- ...
```

このコマンドはファイルを変更しません。
